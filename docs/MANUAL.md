# 동백 활동지원센터 프로그램 사용 매뉴얼

> **최종 업데이트:** 2026-09-14
> 자주 사용하는 기능과 반드시 지켜야 할 상태 변경 절차만 간단히 정리했습니다.

## 1. 화면 이동과 설치

| 메뉴 | 주요 용도 |
| :--- | :--- |
| **대시보드** | 이용자·지원사·매칭·상담·종결 현황 확인 |
| **업무 종합 보드** | 할 일, 월간 달력, 바로가기, 매칭 필요 명단, 연간 일정 관리 |
| **이용자 관리** | 이용자 정보, 바우처, 담당 지원사, 상담·매칭·계약 이력 관리 |
| **활동지원사 관리** | 지원사 정보, 검진일, 담당 이용자, 매칭·입퇴사 이력 관리 |
| **매칭 관리** | 조건별 추천 확인, 매칭 시도·실패·성공 기록 |
| **상담기록 / 문서** | 상담일지, 종결승인서, 인계·인수서, 급여변경 사유서 작성 |

* 스마트폰에서는 본문을 좌우로 밀어 인접 메뉴로 이동할 수 있습니다. 입력칸과 버튼 위에서는 스와이프가 작동하지 않습니다.
* 상단 **앱 설치/바로가기** 버튼을 이용하면 스마트폰이나 PC 바탕화면에서 아이콘으로 실행할 수 있습니다.

## 2. 업무 종합 보드

### 할 일과 바로가기

* 할 일을 등록한 뒤 체크하면 완료 처리됩니다. 별표로 중요 표시하고, 완료 항목만 모아보거나 비울 수 있습니다.
* 바로가기는 카드 클릭 시 새 탭으로 열립니다. 이름과 주소를 수정하거나 **새 바로가기 추가**로 업무 링크를 더할 수 있습니다.

### 이번 달 업무 달력

1. 날짜를 선택하고 제목, 시작·종료 날짜, 시작·종료 시간, 색상, 메모를 입력합니다.
2. 일정 블록을 누르면 상세 내용을 확인하고 수정·삭제할 수 있습니다.
3. 일정을 마우스로 끌어 다른 날짜로 옮길 수 있고, 일정 끝을 조절해 기간을 변경할 수 있습니다.
4. 같은 날짜에 여러 일정이 있으면 서로 다른 색상 선으로 구분됩니다.

### 연간 일정

* 연간사업명, 상태, 업무준비 시작일, 담당, 비고를 입력합니다.
* 사업계획·기안·조사·예약·시행·평가 등 세부 일정을 자유롭게 추가·수정·삭제할 수 있습니다.
* 연간 일정 날짜는 해당 월의 업무 달력에 자동 표시되며, 연간 일정에서 수정하면 달력도 함께 변경됩니다.
* 완료된 일정은 **연간일정 시작일** 안내 보드에서 제외됩니다.

### 매칭 필요 명단

1. 이용자 또는 활동지원사를 검색해 선택합니다.
2. 기본은 **1:1**, 기존 서비스를 유지하면서 추가 매칭이 필요하면 **1:다**를 선택합니다.
3. 실제 매칭 조건을 메모에 구체적으로 작성합니다. 이 메모와 대상자 정보를 기준으로 추천 1~3순위가 표시됩니다.
4. 이름을 누르면 상세 정보로 이동하고, 필요 없어진 항목은 X 버튼으로 삭제합니다.

## 3. 이용자 관리

### 등록·수정과 바우처

* 이름, 연락처, 장애정보, 주소, 필요시간, 지원종류, 유의사항을 입력합니다.
* 바우처 구간과 시간을 직접 입력할 수 있습니다. **시도 추가시간 + 시군구 추가시간**은 자동 합산됩니다.
* 바우처 변경 이력을 추가하면 급여변경 사유서 작성 여부를 묻습니다. 사유서를 저장하면 변경 후 구간과 지원종류가 이용자 정보에 반영됩니다.
* 카드에는 가장 최근 바우처 정보가 표시됩니다.

### 일괄 작업과 대기 매칭대장

* **일괄 업로드**는 신규 등록용, **일괄 정보 업데이트**는 기존 인원의 검진일·연락처 등 수정용입니다.
* 미리보기에서 대상자와 업데이트 컬럼을 확인한 뒤 실행하세요. 성공/실패 건수를 반드시 확인합니다.
* **대기 매칭대장 미리보기**에서 조회 기간을 지정하고 화면 확인 후 A4 인쇄 또는 Word 저장을 할 수 있습니다.

### 종결·계약해지 절차

> 상태만 먼저 바꾸지 마세요. **종결승인서를 최종 저장해야** 계약해지 또는 매칭 대기가 실제 반영됩니다.

1. 이용자 상세 상단에서 **종결**을 누릅니다.
2. **계약해지** 또는 **매칭을 위한 대기**를 선택합니다.
3. 종결일, 사유, 종결 후 지원사 상태를 입력하고 종결승인서를 저장합니다.
4. 저장 시 이용자 서비스 종료일, 담당 지원사의 해당 서비스 종료일, 양쪽 배정과 매칭 이력이 함께 정리됩니다.
5. 이미 계약해지된 이용자는 **종결승인서 작성/보기** 버튼을 이용합니다.

* 계약 이력에는 재계약을 포함해 “1차 시작일~종료일”, “2차 시작일~서비스중” 형태로 표시됩니다.
* 이용자 상태 배지: **서비스중(초록)**, **대기중(주황)**, **계약해지(빨강)**

## 4. 활동지원사 관리

### 상태 배지 이해하기

| 실제 상태 | 화면 표시 |
| :--- | :--- |
| 담당 이용자가 1명 이상 | **재직중 + 서비스 제공중** |
| 담당 이용자가 없고 새 매칭 대기 | **재직중 + 대기** |
| 센터 근무 종료 | **퇴사** |

### 퇴사·대기 전환

1. 상세 상단의 **퇴사/대기 전환**을 누릅니다.
2. 담당 이용자가 있으면 먼저 대상자별 **인계인수서 작성** 또는 **종결승인서 작성**으로 이동합니다.
3. 문서를 저장해 기존 서비스를 종료한 뒤 대기 또는 퇴사를 확정합니다.
4. 담당 이용자가 없으면 기준일을 입력해 바로 **매칭 필요 대기상태** 또는 **퇴사**로 전환할 수 있습니다.

* 입퇴사 이력에는 퇴사 후 재입사한 기간도 차수별로 표시됩니다.
* 검진일 일괄 업데이트 후 **미검진자 모아보기**에서 직장검진과 향정신성/마약검사 명단을 구분해 확인·복사할 수 있습니다.

## 5. 매칭과 인계·인수

### 매칭 기록

* **시도/실패:** 이용자와 지원사를 서비스중으로 바꾸지 않습니다. 실패 사유는 다음 추천의 비적합 조건에 반영됩니다.
* **성공(매칭):** 성공한 경우에만 양쪽 담당 목록과 서비스 상태가 갱신됩니다.
* 매칭 이력은 이용자와 활동지원사 상세에서 동일하게 확인할 수 있습니다.

### 인계·인수서

1. 이용자, 전임 지원사, 후임 지원사, 인계일, 인수일과 내용을 입력합니다.
2. 저장하면 전임 지원사의 종료일과 후임 지원사의 시작일이 자동 기록됩니다.
3. 서비스가 연속되거나 겹치면 지원사 이름 사이에 “+”, 공백 후 교체되면 “→”로 표시됩니다.

## 6. 상담기록·문서와 맞춤법 검사

* 상담일지, 인계·인수서, 종결승인서, 급여변경 사유서는 저장 전 대상자와 날짜를 다시 확인합니다.
* 장문 입력란의 **✨ 맞춤법 검사** 버튼을 눌렀을 때만 해당 입력란의 문장이 서버로 전송됩니다.
* 바른 AI 키 입력이 필요한 경우 안내창에 입력합니다. 키는 브라우저 저장소나 문서에 저장되지 않고 현재 실행 중인 화면에서만 사용됩니다.
* 교정 결과에서 추천어 하나를 적용하거나 전체 교정을 적용할 수 있습니다. 통신 실패 시 원문은 변경되지 않습니다.
* 공식 문서는 인쇄 버튼을 사용하면 A4 규격으로 출력됩니다. 인쇄창에서 용지는 **A4**, 배율은 **기본값/100%**로 확인하세요.

## 7. 안전하게 사용하는 방법

* 동명이인은 이름만 보지 말고 연락처 끝자리까지 확인합니다.
* 담당자 변경은 이용자와 지원사 화면에서 각각 따로 수정하지 말고 매칭 또는 인계·인수 절차를 이용합니다.
* 저장 완료 알림을 확인하고, 카드와 상세 이력에 값이 반영됐는지 한 번 더 확인합니다.
* 저장 실패 안내가 나오면 자동 이동한 입력칸의 필수값을 보완한 뒤 다시 저장합니다.
* 삭제는 되돌리기 어려우므로 대상자 이름과 문서 종류를 확인한 뒤 진행합니다.

> 문제가 계속되면 대상자 이름, 사용 메뉴, 실행 날짜, 표시된 오류 메시지와 화면 캡처를 함께 전달해 주세요.
