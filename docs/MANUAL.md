## 1. 전체 화면 구성

### 1-1. 상단 메뉴

상단에는 주요 업무 메뉴가 가로로 배치됩니다.

| 메뉴명 | 주요 기능 및 역할 |
| :--- | :--- |
| **대시보드** | 센터 전체 현황을 요약해서 확인합니다. |
| **이용자 관리** | 이용자 등록, 수정, 계약 상태, 담당 활동지원사, 상담/매칭 이력을 관리합니다. |
| **활동지원사 관리** | 활동지원사 등록, 수정, 근무 상태, 담당 이용자, 상담/매칭 이력을 관리합니다. |
| **매칭 관리** | 이용자 조건과 활동지원사 조건을 비교해 추천 매칭을 확인합니다. |
| **상담기록** | 이용자 또는 활동지원사 상담 내역을 기록합니다. |
| **종결확인서** | 서비스 종결 관련 문서를 작성하고 관리합니다. |
| **인계·인수서** | 담당자 변경 시 필요한 인계·인수 내용을 작성합니다. |
| **사용 매뉴얼** | 현재 문서를 앱 안에서 확인합니다. |

> 💡 **모바일 화면 안내**  
> 모바일에서는 메뉴가 접히는 방식이 아니라 **가로 스크롤 탭**으로 표시됩니다. 손가락으로 좌우로 밀어 원하는 메뉴를 선택하면 됩니다. 현재 선택된 메뉴는 색상과 밑줄로 강조됩니다.

### 1-2. 메인 대시보드

메인 대시보드는 센터 전체를 보는 종합 현황판입니다. 전체 이용자 수, 전체 활동지원사 수, 현재 매칭률 등 큰 흐름을 확인할 때 사용합니다.

## 2. 이용자 관리 화면 사용법

이용자 관리 화면은 **좌우 2분할 구조**로 설계되어 있습니다.

### 2-1. 좌측 영역: 전체 이용자 명단

좌측에는 검색창, 상태 필터, 이용자 카드 목록이 있습니다.

* **검색창:** 이용자 이름, 연락처, 담당 활동지원사 이름/연락처로 검색할 수 있습니다.
* **상태 필터:** `전체`, `서비스중`, `대기`, `계약해지`를 선택해 목록을 좁힐 수 있습니다.
* **이용자 카드:** 이름, 성별, 나이, 연락처, 장애유형, 최초접수일, 담당지원사, 상태 뱃지를 표시합니다.
* **카드 클릭:** 이용자 상세 정보 팝업이 열립니다.
* **연필 버튼 (`✏️`):** 이용자 수정 팝업이 열립니다.
* **삭제 버튼 (`🗑️`):** 삭제 확인 창이 열립니다.

### 2-2. 우측 영역: 이용자 현황 요약 대시보드

우측 상단에는 최근 3개월 중심의 핵심 지표 카드가 있습니다.

* **3개월 신규 계약:** 최근 3개월 안에 최초서비스제공일 또는 접수일이 있는 이용자 수입니다.
* **3개월 서비스 해지:** 최근 3개월 안에 계약해지일이 있거나 계약해지 상태인 이용자 수입니다.
* **현재 대기자:** 서비스 시작 전이거나 담당 활동지원사가 없는 이용자 수입니다.
* **인계/변경:** 최근 3개월 안에 인계 또는 교체 관련 매칭 이력이 있는 건수입니다.
* **이용자 상담:** 최근 3개월 안에 기록된 이용자/보호자 상담 건수입니다.
* **미처리 상담:** 최근 상담 중 처리 결과가 없거나 미처리로 남은 건수입니다.

### 2-3. 우측 하단: 선택된 현황 상세 명단

요약 카드를 클릭하면 우측 하단에 조건에 맞는 명단이 바로 표시됩니다.

* **표시 컬럼:** `이름` | `주요 일자` (계약일, 해지일, 상담일 등 기준 날짜) | `상태 뱃지` | `비고/사유` | `상세 버튼`
* **상세 이동:** 상세 버튼 또는 행을 클릭하면 해당 이용자의 상세 정보 팝업으로 이동합니다. 0건이면 **“해당 조건에 해당하는 대상자가 없습니다.”**라고 표시됩니다.

## 3. 활동지원사 관리 화면 사용법

활동지원사 관리 화면도 **좌우 2분할 구조**입니다.

### 3-1. 좌측 영역: 전체 활동지원사 명단

좌측에는 검색창, 상태 필터, 지원 가능 종류 필터, 활동지원사 카드 목록이 있습니다.

* **검색창:** 활동지원사 이름, 연락처, 담당 이용자 이름/연락처로 검색할 수 있습니다.
* **상태 필터:** `전체`, `근무중`, `대기`, `퇴사`로 목록을 좁힙니다.
* **지원 가능 종류 필터:** 신체지원, 가사지원, 사회지원 등 가능 업무 기준으로 목록을 좁힙니다.
* **활동지원사 카드:** 이름, 성별, 나이, 연락처, 경력, 지원가능 업무, 최초접수일, 담당이용자, 상태 뱃지를 표시합니다.
* **카드 클릭:** 활동지원사 상세 정보 팝업이 열립니다.
* **연필 버튼 (`✏️`):** 활동지원사 수정 팝업이 열립니다.
* **삭제 버튼 (`🗑️`):** 삭제 확인 창이 열립니다.

### 3-2. 우측 영역: 활동지원사 현황 요약 대시보드

우측 상단에는 활동지원사 기준의 핵심 지표 카드가 있습니다.

* **3개월 신규 입사:** 최근 3개월 안에 최초근무일이 있는 활동지원사 수입니다.
* **3개월 퇴사:** 최근 3개월 안에 퇴사일이 기록된 활동지원사 수입니다.
* **현재 근무 중:** 현재 근무중 상태인 활동지원사 수입니다.
* **현재 대기:** 현재 매칭 대기 중인 활동지원사 수입니다.
* **인계/변경:** 최근 3개월 안에 담당 이용자 변경 또는 인계 이력이 있는 건수입니다.
* **상담/보고:** 최근 3개월 안에 접수된 고충 상담, 현장 보고, 모니터링 기록 건수입니다.

### 3-3. 우측 하단: 조건별 상세 명단

요약 카드를 클릭하면 해당 활동지원사 명단이 즉시 표시됩니다.

* **"3개월 퇴사" 클릭:** 퇴사자 이름, 퇴사일, 상태, 퇴사 사유가 표시됩니다.
* **"현재 대기" 클릭:** 대기 중인 활동지원사 이름, 대기 기준일, 희망지역이 표시됩니다.
* **"상담/보고" 클릭:** 상담 또는 보고 대상자, 날짜, 상담 분류, 주요 내용이 표시됩니다.

> 💡 **상세 팝업 이동**  
> 행 또는 상세 버튼을 누르면 해당 활동지원사의 상세 정보 팝업으로 이동합니다.

## 4. 매칭 관리 화면 사용법

매칭 관리는 이용자 조건과 활동지원사 조건을 비교해 적합한 활동지원사를 추천하는 화면입니다.

### 4-1. 좌측 영역 (조건 설정)

좌측에서는 매칭할 이용자를 선택하고 활동지원사 후보 필터를 조정합니다.

* **이용자 검색:** 대기 이용자 중 이름으로 검색합니다.
* **외국인만:** 외국인 활동지원사만 후보로 봅니다.
* **주말가능:** 토요일 또는 일요일 근무가 가능한 활동지원사만 봅니다.
* **업무별 가능 필터:** 신체지원, 가사지원, 사회지원 등 필요한 지원 유형으로 후보를 좁힙니다.

### 4-2. 우측 영역 (매칭 분석 및 추천)

이용자를 선택하면 우측에서 이용자 정보, 상담 이력, 수동 매칭, 추천 결과를 확인할 수 있습니다.

> **📊 매칭 점수 산정 기준**  
> 1. 시간 적합도  
> 2. 위치 근접도  
> 3. 이용자 선호 조건  
> 4. 활동지원사 거부 조건 또는 제한 조건  
> *(※ 추천 결과에서 활동지원사를 클릭하면 상세 정보를 확인할 수 있습니다.)*

### 4-3. 매칭 성과 대시보드

매칭 관리 상단의 요약 카드를 클릭하면 성사된 매칭 쌍 또는 현재 대기 명단을 확인할 수 있습니다.

* **매칭 성공:** 현재 서비스 중인 이용자-활동지원사 쌍과 매칭 성사일을 확인합니다.
* **매칭 대기:** 매칭을 기다리는 이용자와 활동지원사를 함께 확인합니다.

## 5. 활동지원사 교체/종료 업무 절차

담당 활동지원사를 변경할 때는 기존 매칭을 먼저 정리해야 합니다. 이 절차는 **1:다 중복 매칭을 예방하고 이력을 남기기 위한 핵심 절차**입니다.

### 5-1. 기존 활동지원사 종료 후 신규 매칭

* **적용 상황:**
  * 기존 활동지원사가 서비스를 종료하고 다른 활동지원사가 새로 투입되는 경우
  * 기존 활동지원사를 대기 또는 퇴사 상태로 변경해야 하는 경우
[처리 순서]

1. 이용자 상세/수정 화면에서 기존 활동지원사 옆 [서비스 종료/교체] 선택 ▼
    
2. 서비스 종료일 입력 (YYYY-MM-DD) ▼
    
3. 종료 후 지원사 상태 선택 (대기 / 퇴사) ▼
    
4. 저장 (기존 활동지원사 연결 해제) ▼
    
5. 신규 활동지원사 선택 및 서비스 시작일 입력 ▼
    
6. 저장 (신규 활동지원사 "현재 서비스중" 활성화)
```

> **📌 종료 후 지원사 상태 구별**  
> - **대기:** 퇴사는 아니며, 다른 이용자와 다시 매칭 가능한 상태입니다.  
> - **퇴사:** 센터 근무가 종료된 상태입니다. 별도 퇴사일도 기록됩니다.

* **처리 결과:**
  * 이용자 상단 담당 활동지원사에는 현재 서비스중인 1명만 표시됩니다.
  * 종료된 활동지원사는 하단 매칭 이력에서 확인합니다.
  * 활동지원사 관리 화면에서도 기존 지원사는 대기 또는 퇴사로 바뀌고 담당 이용자 목록에서 제외됩니다.

### 5-2. 인계·인수 교체

* **적용 상황:**
  * 기존 활동지원사와 신규 활동지원사 사이에 인계 내용 기록이 필요한 경우
  * 서비스 특이사항, 보호자 요청, 위험요소, 일정 등을 문서로 남겨야 하는 경우

* **처리 순서:**
  1. 담당 활동지원사를 교체하려고 하면 인계·인수서 작성 안내가 표시됩니다.
  2. 인계·인수서 작성 화면으로 이동합니다.
  3. 기존 지원사, 신규 지원사, 이용자, 인계 내용, 변경 사유를 작성합니다.
  4. 인계·인수서가 저장되면 매칭 변경이 승인됩니다.
  5. 변경 이력에는 사유가 `인계` 또는 `교체`로 기록됩니다.

### 5-3. 1:다 중복 매칭 경고가 뜨는 경우

> ⚠️ **경고 발생 기준:** 한 이용자에게 현재 서비스중 활동지원사가 2명 이상인 경우

* **조치 방법:**
  1. 이용자 상세 화면에서 활동지원사별 서비스 기간 목록을 확인합니다.
  2. 실제 현재 담당자 1명만 **“현재 서비스 중”**으로 유지합니다.
  3. 나머지 활동지원사는 서비스 종료일을 입력합니다.
  4. 종료된 활동지원사는 매칭 이력으로 이동합니다.
  5. 필요하면 종료 후 상태를 대기 또는 퇴사로 정리합니다.

> ⛔ **주의 사항:** 현재 담당 활동지원사는 원칙적으로 1명만 유지하는 것을 권장합니다. 예외적으로 복수 서비스가 실제 운영 정책에 맞는 경우에는 각 지원사의 기간과 사유를 명확히 기록해야 합니다.

### 7-3. `matchingHistory` 컬렉션 및 문서 내부 이력

매칭 이력은 별도 `matchingHistory` 컬렉션과 문서 내부 `matchingHistory` 배열 형태로 관리될 수 있습니다. 프로그램은 화면 조회와 상태 정리를 위해 두 구조를 함께 고려합니다.

* **주요 필드:**
  * `type`: 매칭, 해제, 시도 등 기록 유형
  * `userId`, `userName`, `userPhone`: 이용자 정보
  * `workerId`, `workerName`, `workerPhone`: 활동지원사 정보
  * `date`, `endDate`: 서비스 시작일(또는 이력 발생일), 서비스 종료일
  * `serviceStartDate`, `serviceEndDate`: 서비스 시작일, 서비스 종료일
  * `reason`: 변경 사유 (`교체`, `추가`, `종료`, `인계`)
  * `reasonDetail`, `notes`: 상세 사유 및 추가 메모

* **변경 사유 코드 분류:**
  * **교체:** 기존 담당자에서 새 담당자로 바뀐 경우
  * **추가:** 기존 담당자를 유지하면서 새 담당자가 추가된 경우
  * **종료:** 서비스 또는 매칭이 종료된 경우
  * **인계:** 인계·인수서 작성이 필요한 담당자 변경인 경우

## 8. 데이터 입력 원칙

### 8-1. 날짜 입력

날짜는 **`YYYY-MM-DD`** 형식으로 입력합니다. (예: `2026-08-25`, `2026-09-01`)

> ⚠️ **입력 순서 제약**  
> 이용자 최초서비스제공일을 입력하려면 **최초접수일이 먼저 입력되어 있어야 합니다.** 최초접수일이 비어 있으면 저장이 막히고 안내 팝업이 표시됩니다.

### 8-2. 담당자 배열 동기화 관리

이용자와 활동지원사는 서로 연결된 데이터입니다. 어느 한쪽에서 배정해도 반대편 데이터가 함께 갱신됩니다.

```

[이용자 문서 배정 시] [활동지원사 문서 배정 시] assignedHelperIds ─── 동기화 갱신 ───► assignedUserIds assigned_workers ─── 동기화 갱신 ───► assigned_users

```

### 8-3. 기존 필드와 신규 필드 동시 유지 (레거시 호환)

레거시 데이터 호환을 위해 일부 필드는 쌍(Pair)으로 자동 저장됩니다.

* **이용자 성별:** `gender` = `txtUSex`
* **활동지원사 성별:** `gender` = `txtHSex`
* **중단 사유:** `terminationReason` = `txtUMemostop`
* **담당 활동지원사:** `assignedHelperIds` = `assigned_workers`
* **담당 이용자:** `assignedUserIds` = `assigned_users`

## 10. 상황별 실무 예시

### 📋 경우 A. 활동지원사 교체/종료 발생

* **상황:** 김동백 이용자의 기존 담당자인 박지원 활동지원사가 **2026-08-31**까지만 근무하고, **2026-09-01**부터 이도움 활동지원사가 투입됩니다.
* **처리 단계:**
  1. 이용자 관리에서 `김동백` 검색 ➔ 상세/수정 화면 오픈
  2. 박지원 옆의 **[서비스 종료/교체]** 선택
  3. 서비스 종료일에 `2026-08-31` 입력
  4. 종료 후 상태를 `대기`로 선택 (실제 퇴사라면 `퇴사` 선택)
  5. 신규 담당 활동지원사로 `이도움` 선택
  6. 서비스 시작일에 `2026-09-01` 입력 ➔ **[저장]**
* **결과 확인:**
  * 김동백 상단 담당자는 **이도움 1명만 표시**됩니다.
  * 박지원은 매칭 이력에서 종료된 담당자로 확인됩니다.
  * 활동지원사 관리에서 박지원은 **대기** 또는 **퇴사** 상태로 표시됩니다.

### 📋 경우 B. 대시보드 인터랙션 활용

* **상황:** 최근 3개월 퇴사자를 빠르게 확인해야 합니다.
* **처리 단계:**
  1. 활동지원사 관리 화면으로 이동
  2. 오른쪽 상단 대시보드에서 **"3개월 퇴사"** 카드 클릭
  3. 오른쪽 하단 상세 명단에서 퇴사자 이름, 퇴사일, 상태, 사유 확인
  4. 특정 지원사의 상세 정보가 필요하면 해당 행 또는 **[상세]** 버튼 클릭

### 📋 경우 C. 매칭 성공 및 이력 관리

* **상황:** 대기 이용자에게 적합한 활동지원사를 찾고, 매칭 이력을 남겨야 합니다.
* **처리 단계:**
  1. 매칭 관리 화면으로 이동 ➔ 좌측에서 대기 이용자 선택
  2. 필요시 외국인, 주말가능, 업무별 가능 필터 조정
  3. 우측 추천 결과에서 점수와 세부 조건 확인
  4. 실제 배정할 활동지원사를 이용자 관리 또는 활동지원사 관리에서 연결
  5. 저장 후 매칭 이력에서 매칭 날짜와 담당자 정보 확인

## 11. 자주 발생하는 문제와 확인 방법 (FAQ)

### Q1. 담당자가 여러 명으로 보입니다.

* **원인:** 과거 담당자의 서비스 종료일이 비어 있거나, "현재 서비스중" 체크가 2명 이상에게 남아 있는 경우입니다.
* **해결 방법:**
  1. 이용자 상세 화면에서 활동지원사별 서비스 기간을 확인합니다.
  2. 실제 현재 담당자 1명만 **"서비스중"**으로 유지합니다.
  3. 과거 담당자에게 서비스 종료일을 입력합니다.
  4. 종료 후 상태를 `대기` 또는 `퇴사`로 정리합니다.

### Q2. 대기자가 너무 많이 보입니다.

* **확인 항목:**
  * 최초서비스제공일이 비어 있는지 확인합니다.
  * 담당 활동지원사가 실제로 배정되어 있는지 확인합니다.
  * 계약상태가 수동으로 `대기` 상태로 설정되어 있는지 확인합니다.

### Q3. 활동지원사가 근무중으로 보이지 않습니다.

* **확인 항목:**
  * 최초근무일이 입력되어 있는지 확인합니다.
  * 퇴사일 또는 `retirementDate`가 입력되어 있지 않은지 확인합니다.
  * 담당 이용자 연결이 정상인지 확인합니다.

### Q4. 스마트폰 화면에서 메뉴가 보이지 않습니다.

* **해결 방법:** 상단 메뉴는 **가로 스크롤 방식**입니다. 메뉴 영역을 좌우로 터치하여 밀어주시면 숨겨진 메뉴를 확인할 수 있습니다.
```
