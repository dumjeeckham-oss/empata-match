# 관리 화면 검색 영역 고정 및 종결 종류 문구 수정

## 변경 내용
- 이용자 관리 화면에서 화면 제목·작업 버튼과 검색/상태 선택 영역을 상단 메뉴 아래에 고정합니다.
- 활동지원사 관리 화면에서 화면 제목·작업 버튼과 검색/필터 영역을 상단 메뉴 아래에 고정합니다.
- 매칭 관리 화면의 이용자·활동지원사 검색 영역을 각 목록 상단에 고정해 목록을 보면서 바로 검색할 수 있게 합니다.
- 종결승인서의 `가족활동가` 표시를 `가족이 직접 돌봄`으로 변경합니다.
- 기존 저장 데이터의 `가족활동가` 값도 새 문구가 선택된 것으로 인식하도록 호환성을 유지합니다.

## 확인
- 데스크톱과 모바일에서 고정 영역이 상단 메뉴와 겹치지 않는지 확인합니다.
- 세 화면의 검색과 필터가 기존대로 작동하는지 확인합니다.
- 종결승인서 입력 화면과 인쇄 화면에 새 문구가 표시되는지 확인합니다.
